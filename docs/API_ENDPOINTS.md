# API endpoint reference

> Generated by `npm run docs:api` from `src/docs/openapi.ts`. Interactive docs: `GET /api/docs` (Swagger UI), raw spec: `GET /api/openapi.json`.

## Auth

| Method | Path | Summary | Roles |
|---|---|---|---|
| `POST` | `/api/v1/auth/register` | Register a patient account (rate limited) | public |
| `POST` | `/api/v1/auth/login` | Log in and receive a JWT | public |
| `GET` | `/api/v1/auth/me` | Current user | any authenticated |
